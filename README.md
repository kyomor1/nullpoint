# nullpoint

Сайт с приложениями Kyo Mori: Converty, FPS Scope и D-Shift.

Статический сайт из одного файла index.html и папки screenshots. Сборка не нужна.

- Данные приложений: массив APPS в index.html.
- Файлы для скачивания лежат в GitHub Releases этого репозитория, по одному релизу на версию (dshift-v0.1.4 и т. д.).
